Gold Trading Partner

Personal project · AI-assisted research tool

A research tool for trading gold: a deterministic rules engine finds trade setups on a live chart, and an AI assistant explains each one step by step on the chart. It never places a trade. It exists to turn a trading strategy into explicit, testable rules.

What I did

  • Built the full product: a Python and FastAPI backend, a browser UI with live charts and chat, and an MQL5 data feed from MetaTrader 5.
  • Designed it so the AI never decides anything. Levels, entries, stops and results come from deterministic code, and the model only explains facts it is given.
  • Logged every decision, taken or dropped, with the reason, so any trade can be explained from the record, and replayed with no hindsight.
  • Backtested the rules and reported win rate, expectancy, profit factor and drawdown. Rule changes are measured before they are switched on.
  • Made the AI layer pluggable across Anthropic, Ollama (local) and OpenRouter models.

MyCove

Estate management platform · mobile, web and API

A platform that runs a residential estate: dues and payments, visitor access, community decisions, and communication between residents, security guards and estate staff.

What I did

  • Designed and built the Flutter mobile app, the NestJS API on PostgreSQL, and the Next.js admin dashboards.
  • Built authentication with short-lived tokens and rotating refresh tokens. When several requests fail at once the app does one shared refresh and retries them, instead of racing.
  • Built five enforced roles: resident, guard, admin, finance secretary and project admin.
  • Built a finance workflow where a Finance Secretary allocates funds to projects and approves invoices raised by a Project Admin. Balances are always calculated from the ledger, never stored, so they cannot drift.
  • Integrated Paystack payments with webhooks behind a gateway interface, plus push notifications for visitor check-ins and payment success.
  • Ran integration tests on a real simulator against the real backend, which caught problems unit tests could not.
